# Expressing Possibility: かもしれない / でしょう

Learn how to talk about things you are not certain about using **かもしれない** (it might be) and **でしょう** (it's probably).

## Key Expressions

| Hiragana | Romaji | English | Type |
|----------|--------|---------|------|
| [short form] + かもしれない | kamoshirenai | might, maybe (casual) | expression |
| [short form] + かもしれません | kamoshiremasen | might, maybe (polite) | expression |
| [short form] + でしょう | deshou | probably, I think (polite) | expression |
| [short form] + だろう | darou | probably (casual) | expression |
| [short form] + かな | kana | I wonder, maybe (casual) | particle |

## Certainty: かもしれない vs でしょう

Both express a guess, but they sit at different levels of confidence.

- **かもしれない** → about 50/50 — "it might be, it might not be"
- **でしょう** → confident — "it's probably the case"

## Pattern 1: かもしれない (Might)

**[verb / adjective / noun — plain form] + かもしれない**

**Meaning:** "It might be that..." / "Maybe..."

### Formation

| Type | Formation |
|------|-----------|
| Verb | [verb plain form] + かもしれない |
| い-Adjective | [い-adjective] + かもしれない |
| な-Adjective | [な-adjective] (drop な) + かもしれない |
| Noun | [noun] + かもしれない |

:::warning No だ before かもしれない
な-adjectives and nouns attach **directly** — do **not** add だ.
- ✓ あめ かもしれない (it might rain)
- ❌ あめ だ かもしれない
:::

### Examples

- あした あめ が ふる かもしれません。 — It might rain tomorrow.
  - *ashita ame ga furu kamoshiremasen.*
- あの みせ は たかい かもしれません。 — That shop might be expensive.
  - *ano mise wa takai kamoshiremasen.*
- きょう は うみ が しずか かもしれません。 — The sea might be calm today.
  - *kyou wa umi ga shizuka kamoshiremasen.*
- かれ は がくせい かもしれません。 — He might be a student.
  - *kare wa gakusei kamoshiremasen.*

:::tip Polite vs Casual
**かもしれません** is the polite form; **かもしれない** is casual. In very casual speech it often shrinks to **かも**: あめ かも (might rain).
:::

:::tip Wondering to Yourself: かな
In casual speech, the ending particle **かな** expresses a guess you are mulling over — "I wonder..." / "maybe...". It attaches to the plain form and is softer and more inward-looking than かもしれない: you're thinking aloud rather than informing someone.

- あした あめ が ふる かな。 — I wonder if it'll rain tomorrow.
  - *ashita ame ga furu kana.*
- そう かな。 — Hmm, is that so? / I'm not so sure.
  - *sou kana.*

The feminine equivalent is **かしら**. Add **な** for a stronger "I really hope..." nuance: あめ が ふらない かな**な** (I hope it won't rain).
:::

## Pattern 2: でしょう (Probably)

**[verb / adjective / noun — plain form] + でしょう**

**Meaning:** "It's probably..." / "I think..."

### Formation

| Type | Formation |
|------|-----------|
| Verb | [verb plain form] + でしょう |
| い-Adjective | [い-adjective] + でしょう |
| な-Adjective | [な-adjective] (drop な) + でしょう |
| Noun | [noun] + でしょう |

:::caution でしょう replaces です
Attach でしょう directly to the plain form — it already carries the meaning of です, so you never say ~です でしょう.
- ✓ あめ でしょう (it'll probably rain)
- ❌ あめ です でしょう
:::

### Examples

- あした あめ が ふる でしょう。 — It'll probably rain tomorrow.
  - *ashita ame ga furu deshou.*
- あの みせ は たかい でしょう。 — That shop is probably expensive.
  - *ano mise wa takai deshou.*
- あの ビーチ は ゆうめい でしょう。 — That beach is probably famous.
  - *ano biichi wa yuumei deshou.*
- かれ は がくせい でしょう。 — He's probably a student.
  - *kare wa gakusei deshou.*

:::tip でしょう？ as a Confirmation
With rising intonation, **でしょう？** asks the listener to agree: "right?" / "don't you think?"
- おいしい でしょう？ — It's delicious, isn't it?
  - *oishii deshou?*
The casual version is **だろう？** (or でしょ？).
:::

## Same Sentence, Both Ways

**かもしれない (uncertain — about 50%):**
- あした あめ が ふる かもしれません。 — It might rain tomorrow (I'm really not sure).
  - *ashita ame ga furu kamoshiremasen.*

**でしょう (confident — probably):**
- あした あめ が ふる でしょう。 — It'll probably rain tomorrow (I'm fairly sure).
  - *ashita ame ga furu deshou.*

## Quick Comparison

**かもしれない** — a 50/50 possibility; you genuinely don't know either way.
**でしょう** — a confident guess; you expect it to be true.

**Certainty scale:** かもしれない (might, ~50%) → でしょう / だろう (probably, ~80%) → にちがいない (surely, ~95%)

**Formality:** でしょう / かもしれません are polite; だろう / かもしれない are casual.
