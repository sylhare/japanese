# Actions and Thinking: ている / とおもう / てみる

Learn three essential sentence patterns: describing ongoing actions and states with **ている**, expressing thoughts and opinions with **と おもう**, and trying an action with **てみる**.

## Key Expressions

| Hiragana | Romaji | English | Type |
|----------|--------|---------|------|
| [verb て] + いる | [te-form] iru | currently doing / in a state of | expression |
| [sentence plain] + と おもう | [sentence] to omou | I think that... | expression |
| [noun] + を かんがえる | [noun] o kangaeru | think about / ponder (topic) | expression |
| [verb て] + みる | [te-form] miru | try doing | expression |
| [verb て] + みよう | [te-form] miyou | let's try doing | expression |

:::tip When to Use Which? おもう vs かんがえる
- **と おもう** — Expresses personal opinions, beliefs, impressions, or predictions (*"I think that..."*). It attaches to a plain-form clause via the quotation particle **と**.
- **を かんがえる** — Expresses deep contemplation, reasoning, or deliberate problem-solving (*"to consider / ponder X"*). It takes a noun or topic with the object particle **を**.
:::

## Pattern 1: Ongoing Actions and States (〜ている)

**[Verb て-form] + いる / います**

**Meaning:** "Currently doing [verb]", "in the state of having done [verb]"

Attach **いる** to the verb's [て-form](/docs/lessons/conjugation/present/te-form). Depending on the verb type, **ている** conveys either an ongoing action (continuous) or an ongoing result of a past change (resulting state).

| Type | Formation |
|------|-----------|
| Verb (Affirmative) | [verb て-form] + いる / います |
| Verb (Negative) | [verb て-form] + いない / いません |
| Verb (Past) | [verb て-form] + いた / いました |

### Examples

**Ongoing Action (Actions in Progress):**
- いま テレビ を みて います。 — I am watching TV right now.
  - *ima terebi o mite imasu.*
- ともだち は にほんご を べんきょうして います。 — My friend is studying Japanese.
  - *tomodachi wa nihongo o benkyou shite imasu.*
- あめ が ふって います。 — It is raining.
  - *ame ga futte imasu.*

**Resulting State (Ongoing Condition):**
- とうきょう に すんで います。 — I live in Tokyo.
  - *toukyou ni sunde imasu.*
- たなかさん を しって います か？ — Do you know Mr. Tanaka?
  - *tanakasan o shitte imasu ka?*
- まだ ひるごはん を たべて いません。 — I haven't eaten lunch yet.
  - *mada hirugohan o tabete imasen.*

:::tip Casual Contraction: てる
In casual conversation, the **い** in **ている** is frequently dropped:
- みている → **みてる** (*miteru*)
- たべている → **たべてる** (*tabeteru*)
- しっている → **しってる** (*shitteru*)
:::

## Pattern 2: Expressing Thoughts and Opinions (〜と おもう)

**[Plain-Form Clause] + と おもう (です / ます)**

**Meaning:** "I think that...", "In my opinion..."

Attach the quotation particle **と** followed by **おもう** (or polite **おもいます**) to a short/plain-form sentence.

| Type | Formation |
|------|-----------|
| Verb | [verb plain form] + と おもう |
| い-Adj | [い-adjective plain form] + と おもう |
| な-Adj | [な-adjective stem] + **だ** + と おもう |
| Noun | [noun] + **だ** + と おもう |

:::caution Don't forget だ for Nouns and な-Adjectives
With verbs and い-adjectives, attach **と おもう** directly to the dictionary form. But with **nouns** and **な-adjectives**, you must include **だ**:
- ✓ あの ひと は にほんじん **だ** と おもいます。 (*I think that person is Japanese.*)
- ✗ あの ひと は にほんじん と おもいます。 (Incorrect)
:::

### Examples

- あした は あめ が ふる と おもいます。 — I think it will rain tomorrow.
  - *ashita wa ame ga furu to omoimasu.*
- この えいが は おもしろい と おもう。 — I think this movie is interesting.
  - *kono eiga wa omoshiroi to omou.*
- この へや は しずか だ と おもいます。 — I think this room is quiet.
  - *kono heya wa shizuka da to omoimasu.*
- かれ は こない と おもいます。 — I don't think he will come.
  - *kare wa konai to omoimasu.*

:::tip Third-Person Thoughts: と おもっている
When describing what someone else is thinking, use **〜と おもっている / おもっています**:
- たなかさん は にほん へ かえりたい と おもっています。 — Mr. Tanaka is thinking that he wants to return to Japan.
  - *tanakasan wa nihon e kaeritai to omotte imasu.*
:::

## Pattern 3: Trying Things Out (〜てみる)

**[Verb て-form] + みる / みます**

**Meaning:** "Try doing [verb]", "do [verb] to see what happens"

Attach **みる** (which conjugates like a normal Ichidan verb) to the [て-form](/docs/lessons/conjugation/present/te-form). Unlike "trying hard" (がんばる), **てみる** means sampling or experimenting.

| Type | Formation |
|------|-----------|
| Present Polite | [verb て-form] + みます |
| Casual / Imperative | [verb て-form] + みて (ください) |
| Volitional ("Let's try") | [verb て-form] + みよう / みましょう |
| Past | [verb て-form] + みた / みました |

### Examples

- この にほんりょうり を たべてみて ください。 — Please try eating this Japanese dish (and see if you like it).
  - *kono nihonryouri o tabete mite kudasai.*
- にほんご で はなしてみます。 — I'll try speaking in Japanese.
  - *nihongo de hanashitemimasu.*
- あたらしい レストラン に いってみよう！ — Let's try going to the new restaurant!
  - *atarashii resutoran ni ittemiyou!*
- もう いちど かんがえてみます。 — I will think it over once more.
  - *mou ichido kangaetemimasu.*
- ふじさん に のぼってみた こと が あります。 — I have tried climbing Mt. Fuji before.
  - *fujisan ni nobottemita koto ga arimasu.*
