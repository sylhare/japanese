# Conditionals: と / たら / ば / なら

Learn how to express "if" and "when" in Japanese using the four conditional patterns: **と**, **たら**, **ば**, and **なら**.

- [**と**](#pattern-1-と-natural-consequences) — natural, automatic consequences
- [**たら**](#pattern-2-たら-specific--hypothetical-situations) — specific situations, completed conditions, and requests
- [**ば**](#pattern-3-ば-general--logical-conditions) — general, hypothetical, or logical conditions
- [**なら**](#pattern-4-なら-context--suppositions) — conditions based on context or what someone just said

## Key Expressions

| Hiragana | Romaji | English | Type |
|----------|--------|---------|------|
| [clause A] + と + [clause B] | to | when/if A, then B | expression |
| [clause A ta-form] + ら + [clause B] | tara | if/when A, then B | expression |
| [clause A ば-form] + [clause B] | ba | if A (generally / hypothetically), then B | expression |
| [clause A plain] + なら + [clause B] | nara | if it's the case that A, then B | expression |

## Pattern 1: と (Natural Consequences)

Use **と** to express that when clause A happens, clause B naturally, automatically, or inevitably follows.

**[clause A plain form] + と, [clause B]**

**Meaning:** "When / whenever A happens, B automatically follows"

### Formation

| Type | Formation | Example |
|------|-----------|---------|
| Verb | [dictionary form] + と | いく → いくと |
| い-Adjective | [い-adjective] + と | やすい → やすいと |
| な-Adjective | [な-adjective] + **だ** + と | しずかだ → しずかだと |
| Noun | [noun] + **だ** + と | あめだ → あめだと |
| Negative | [plain negative] + と | いかない → いかないと |

:::caution No commands, requests, or intentions with と
Because **と** expresses an automatic, natural result beyond the speaker's control, clause B **cannot** be a request, command, suggestion, or expression of personal intention (e.g. 〜てください, 〜ましょう, 〜たい).
- ❌ えきに つくと、でんわしてください。
- ✓ えきに ついたら、でんわしてください。 — When you arrive at the station, please call me. (Use **たら** for requests!)
:::

### Examples

**Natural consequences** — something that always happens when A occurs:

- はるに なると、はなが さきます。 — When spring comes, the flowers bloom.
  - *haru ni naru to, hana ga sakimasu.*
- この ボタンを おすと、でんきが つきます。 — When you press this button, the light turns on.
  - *kono botan o osu to, denki ga tsukimasu.*

**Universal truths and facts:**

- ふゆに なると、さむくなります。 — When winter comes, it gets cold.
  - *fuyu ni naru to, samuku narimasu.*
- みずを あたためると、おゆに なります。 — When you heat water, it becomes hot water.
  - *mizu o atatameru to, o-yu ni narimasu.*

**Directions and predictable outcomes:**

- まっすぐ いくと、こうえんが みえます。 — If you go straight, you'll see the park.
  - *massugu iku to, kouen ga miemasu.*
- みぎに まがると、えきが あります。 — If you turn right, there's a station.
  - *migi ni magaru to, eki ga arimasu.*


## Pattern 2: たら (Specific & Hypothetical Situations)

Use **たら** for specific, one-time situations — things that might happen, completed conditions, requests after an action, or hypothetical scenarios.

**[clause A た-form] + ら, [clause B]**

**Meaning:** "If / when A happens, then B"

### Formation

| Type | Formation | Example |
|------|-----------|---------|
| Verb | [た-form] + ら | いった → いったら |
| い-Adjective | [〜かった] + ら | たかかった → たかかったら |
| な-Adjective | [〜だった] + ら | しずかだった → しずかだったら |
| Noun | [noun + だった] + ら | あめだった → あめだったら |
| Negative | [〜なかった] + ら | いかなかった → いかなかったら |

:::tip Formation Shortcut
If you know the [た-form](/docs/lessons/conjugation/past/ta-form), just add **ら**. That's all!
:::

### Examples

**Requests and suggestions** — when you want someone to do something after a condition is met:

- えきに ついたら、でんわしてください。 — When you arrive at the station, please call me.
  - *eki ni tsuitara, denwa shite kudasai.*
- じかんが あったら、あそびに きてね。 — If you have time, come hang out.
  - *jikan ga attara, asobi ni kite ne.*

**Hypothetical situations** — imagining "what if":

- たからくじに あたったら、にほんに いきたい。 — If I won the lottery, I'd want to go to Japan.
  - *takarakuji ni atattara, nihon ni ikitai.*
- あめが ふったら、うちに いよう。 — If it rains, let's stay home.
  - *ame ga futtara, uchi ni iyou.*

**Discovery** — when you did something and found an unexpected result:

- まどを あけたら、ゆきが ふっていた。 — When I opened the window, it was snowing.
  - *mado o aketara, yuki ga futte ita.*
- いえに かえったら、ともだちが いた。 — When I got home, my friend was there.
  - *ie ni kaettara, tomodachi ga ita.*

**Advice:**

- わからなかったら、せんせいに きいてください。 — If you don't understand, please ask the teacher.
  - *wakaranakattara, sensei ni kiite kudasai.*
- つかれたら、やすんだ ほうが いい。 — If you're tired, you should rest.
  - *tsukaretara, yasunda hou ga ii.*


## Pattern 3: ば (General & Logical Conditions)

Use **ば** for general conditions, logical results, and hypotheticals — "if A is true, B follows." It focuses attention on the **condition itself**.

**[clause A ば-form] + [clause B]**

**Meaning:** "If A (is true / happens), then B"

### Formation

| Type | Formation | Example |
|------|-----------|---------|
| Group 1 Verbs (Godan) | final *-u* → *-eba* | のむ → のめば |
| Group 2 Verbs (Ichidan) | drop る, add れば | たべる → たべれば |
| Irregular Verbs | する → すれば / くる → くれば | する → すれば |
| い-Adjective | drop い, add ければ | やすい → やすければ |
| な-Adjective / Noun | add なら(ば) or であれば | しずか → しずかなら(ば) / であれば |
| Negative | ない → なければ | いかない → いかなければ |

:::tip いい is irregular
The adjective **いい** (good) becomes **よければ**, not ~~いければ~~ — it uses its original stem **よい**.
:::

### Examples

- ボタンを おせば、ドアが あきます。 — If you press the button, the door opens.
  - *botan o oseba, doa ga akimasu.*
- やすければ、かいます。 — If it's cheap, I'll buy it.
  - *yasukereba, kaimasu.*
- れんしゅうすれば、じょうずに なります。 — If you practice, you'll get better.
  - *renshuu sureba, jouzu ni narimasu.*
- じかんが なければ、いかなくても いいです。 — If you don't have time, you don't have to go.
  - *jikan ga nakereba, ikanakute mo ii desu.*

:::tip 〜ば〜ほど — "the more… the more"
Repeat the verb with **ほど** to show that as one thing increases, so does another:
- たべれば たべる ほど、ふとります。 — The more you eat, the fatter you get.
  - *tabereba taberu hodo, futorimasu.*
:::

:::caution Avoid ば for direct requests
When clause B is a command, request, or invitation, **ば** sounds unnatural — use **たら** instead.
- ❌ えきに つけば、でんわしてください。
- ✓ えきに ついたら、でんわしてください。 — When you arrive at the station, please call me.
:::


## Pattern 4: なら (Context & Suppositions)

Use **なら** when the condition is based on **context** — something the other person said, a topic that just came up, or a supposition. It means "if it's the case that A, then B."

**[clause A plain / noun] + なら, [clause B]**

**Meaning:** "If it's the case that A...", "If we're talking about A..."

### Formation

| Type | Formation | Example |
|------|-----------|---------|
| Verb | [plain form] + なら | いく → いくなら |
| い-Adjective | [い-adjective] + なら | やすい → やすいなら |
| な-Adjective | [stem] + なら | ひま → ひまなら |
| Noun | [noun] + なら | ビール → ビールなら |
| Negative | [plain negative] + なら | いかない → いかないなら |

### Examples

- にほんに いくなら、きょうとが おすすめです。 — If you're going to Japan, I recommend Kyoto.
  - *nihon ni iku nara, kyouto ga osusume desu.*
- あなたが いくなら、わたしも いきます。 — If you're going, then I'll go too.
  - *anata ga iku nara, watashi mo ikimasu.*
- ビールなら、れいぞうこに あります。 — If it's beer (you want), there's some in the fridge.
  - *biiru nara, reizouko ni arimasu.*

:::info なら can put B before A in time
Unlike と / たら / ば — where A always happens first — with **なら** the main action in clause B can happen **before** clause A:
- にほんに いくなら、カメラを かった ほうが いい。 — If you're going to Japan, you should buy a camera (before you go).
  - *nihon ni iku nara, kamera o katta hou ga ii.*
:::


## Same Situation, Four Ways

To see how the four conditionals differ in practice, compare how they change the meaning of a single scenario:

### Scenario 1: Going to Japan (にほんに いく)

- **と (Automatic consequence when A happens):**
  - にほんに いくと、いつも たのしいです。 — Whenever I go to Japan, it's always fun.
    - *nihon ni iku to, itsumo tanoshii desu.*
- **たら (Specific situation / after arriving):**
  - にほんに いったら、ラーメンを たべたい。 — When I go to Japan (once I arrive), I want to eat ramen.
    - *nihon ni ittara, raamen o tabetai.*
- **ば (Logical condition):**
  - にほんに いけば、にほんごが じょうずに なります。 — If you go to Japan, your Japanese will improve.
    - *nihon ni ikeba, nihongo ga jouzu ni narimasu.*
- **なら (Context / before taking action):**
  - にほんに いくなら、きょうとが おすすめです。 — If you're going to Japan (since you mentioned it), Kyoto is recommended.
    - *nihon ni iku nara, kyouto ga osusume desu.*

### Scenario 2: Buying something cheap

- **と (Automatic habit/reaction):**
  - やすいと、かいます。 — When/if it's cheap, I buy it. *(habitual reaction)*
    - *yasui to, kaimasu.*
- **ば (General logical rule):**
  - やすければ、かいます。 — If it's cheap, I'll buy it. *(a general personal rule)*
    - *yasukereba, kaimasu.*
- **なら (Context-based reaction):**
  - やすいなら、かいます。 — If it's cheap (as you say), I'll buy it. *(reacting to what you just told me)*
    - *yasui nara, kaimasu.*
- **たら (Specific condition met):**
  - やすかったら、かいます。 — If it turns out to be cheap, I'll buy it. *(if/when I check the price)*
    - *yasukattara, kaimasu.*


## Quick Comparison

| Pattern | Key Nuance | Main Restriction / Best Use |
|---------|------------|------------------------------|
| **と** | Natural / automatic consequence | Clause B **cannot** be a request, command, or intention. |
| **たら** | Specific one-time situation, sequence | Safest all-around conditional; mandatory for **requests/commands**. |
| **ば** | General, hypothetical, or logical condition | Unnatural for direct requests; used in proverbs and idioms (`〜ば〜ほど`). |
| **なら** | Context-based, topic reaction, supposition | Clause B action can happen **before** clause A in time. |

:::tip When in doubt, use たら
**たら** fits the widest range of situations and is natural in almost any conversational context, so it's the safest choice when speaking.
:::
