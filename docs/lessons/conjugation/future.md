# Future in Japanese

Japanese does not have a separate future tense. Verbs have only two grammatical tenses: **past** (かこ / 過去 - *kako*) and **non-past** (ひかこ / 非過去 - *hikako*).

The present or non-past form (dictionary form in casual speech, ます form in polite speech) expresses both habitual actions and future events when paired with time words or clear context.

To explicitly express **will**, **intention**, or an invitation ("let's...", "I will..."), Japanese uses the **volitional form** (いこうけい / 意向形 - *ikoukei*).

The future and volitional form are used to:
- Express planned or scheduled future actions
- Express personal will or determination ("I will...", "I'm going to...")
- Make casual invitations or suggestions ("Let's...")
- Express future plans with 〜と おもう ("I think I will...")

:::tip Polite Form Equivalent
For polite speech, use the **〜ましょう** (-mashou) ending instead of the plain volitional form:
- たべよう → **たべましょう** (let's eat)
- いこう → **いきましょう** (let's go)
- しよう → **しましょう** (let's do)

To make a polite suggestion or offer ("Shall we?" / "Shall I?"), add the question particle **か**:
- **〜ましょうか** — e.g. てつだいましょうか (Shall I help?)
:::

## Expressing Future with the Non-Past Form

Because Japanese has no dedicated future tense conjugation, the standard **dictionary form** (casual) and **ます form** (polite) express future actions when combined with future time words or context:

| Time Word | Kanji | Romaji | Meaning |
|-----------|-------|--------|---------|
| あした | 明日 | ashita | tomorrow |
| あさって | 明後日 | asatte | day after tomorrow |
| らいしゅう | 来週 | raishuu | next week |
| らいげつ | 来月 | raigetsu | next month |
| らいねん | 来年 | rainen | next year |
| こんばん | 今晩 | konban | tonight |
| あとで | 後で | ato de | later |

:::tip Time Vocabulary
For a complete guide to time expressions, see [Days and Weeks](/docs/lessons/vocabulary/time/days-and-weeks) and [Calendar](/docs/lessons/vocabulary/time/calendar).
:::

Compare habitual present and future meaning with the same verb form:

- まいにち にほんご を べんきょうします。 — I study Japanese every day.
  - *mainichi nihongo o benkyoushimasu.*
- あした にほんご を べんきょうします。 — I will study Japanese tomorrow.
  - *ashita nihongo o benkyoushimasu.*

## Group 1 (Godan) — Change to お-column + う

For Godan verbs, change the final **う-sound** to its corresponding **お-column** syllable and add **う** (producing an elongated *ō* sound):

| Ending | Volitional Form | Pattern |
|--------|-----------------|---------|
| く | こう | ku → kou |
| ぐ | ごう | gu → gou |
| す | そう | su → sou |
| つ | とう | tsu → tou |
| る | ろう | ru → rou |
| う | おう | u → ou |
| ぬ | のう | nu → nou |
| む | もう | mu → mou |
| ぶ | ぼう | bu → bou |

:::tip Memory Trick
Every Godan ending shifts to the **お (o)** row, then adds **う (u)**:
- か**く** (ku) → か**こ** (ko) + う → か**こう** (kakou)
- はな**す** (su) → はな**そ** (so) + う → はな**そう** (hanasou)
:::

### Examples

- かく → かこう (let's write / will write)
- およぐ → およごう (let's swim / will swim)
- はなす → はなそう (let's speak / will speak)
- まつ → まとう (let's wait / will wait)
- つくる → つくろう (let's make / will make)
- かう → かおう (let's buy / will buy)
- しぬ → しのう (let's die / will die)
- よむ → よもう (let's read / will read)
- あそぶ → あそぼう (let's play / will play)

## Group 2 (Ichidan) — Drop る, add よう

For Ichidan verbs (verbs ending in る preceded by an *i* or *e* sound), drop **る** and add **よう**:

| Ending | Volitional Form | Pattern |
|--------|-----------------|---------|
| る | よう | ru → you |

### Examples

- たべる → たべよう (let's eat / will eat)
- みる → みよう (let's see / will watch)
- おきる → おきよう (let's wake up / will wake up)
- ねる → ねよう (let's sleep / will sleep)
- でる → でよう (let's leave / will go out)
- おぼえる → おぼえよう (let's remember / will memorize)
- かんがえる → かんがえよう (let's think / will consider)
- おしえる → おしえよう (let's teach / will teach)

## Group 3 (Irregular)

Both irregular verbs change their stem vowel before adding the volitional ending:

- する → **しよう** (shiyou - let's do / will do)
- くる → **こよう** (koyou - let's come / will come)

:::warning Irregular Reading: くる (to come)
The verb **くる** (*kuru* - to come, kanji 来る) changes its reading to **こ** in the volitional form:
- くる (来る) → **こよう (来よう)**, NOT ~~くよう~~ or ~~きよう~~
:::

### Examples with する Compounds

Compound verbs with する follow the exact same pattern:

- べんきょうする → べんきょうしよう (let's study / will study)
- さんぽする → さんぽしよう (let's take a walk / will take a walk)
- りょこうする → りょこうしよう (let's travel / will travel)
- そうじする → そうじしよう (let's clean / will clean)

## Future in Context

**Casual invitation ("Let's..."):**
> いっしょに えいが を **みよう**。
> *Let's watch a movie together.*

**Personal resolve or intention ("I will..."):**
> こんしゅう は まいにち **はしろう**。
> *I'm going to run every day this week.*

**Intention with 〜と おもう ("I think I will..."):**
> あした は はやく **おきよう** と おもいます。
> *I think I'll wake up early tomorrow.*

**Scheduled future action (Non-past + time word):**
> らいしゅう ともだち に **あいます**。
> *I will meet my friend next week.*

**Polite invitation or suggestion ("Shall we..."):**
> ちょっと **やすみましょう** か。
> *Shall we take a short break?*

:::info Common Future Patterns
While verb conjugation provides the base through non-past and volitional forms, Japanese also uses specialized grammar patterns for expressing future intentions and plans:

- **〜よう と おもう / と おもっている** — thinking of doing (volitional + と おもう): にほん へ いこう と おもっている (I'm thinking of going to Japan) → see [Actions and Thinking](/docs/lessons/grammar/actions-and-events/actions-and-thinking)
- **[Dictionary form] + つもり** — firm personal intention: らいねん りゅうがくする つもり です (I intend to study abroad next year) → see [Expressing Intention - つもり](/docs/lessons/grammar/explaining-and-reasoning/intend-to)
- **[Dictionary form] + よてい** — scheduled plan: あした しゅっぱつする よてい です (I'm scheduled to depart tomorrow) → see [つもり vs よてい](/docs/lessons/grammar/explaining-and-reasoning/intend-to#つもり-vs-よてい)
- **[Dictionary form] + ことにする** — decide to do: まいにち うんどう することにする (I decide to exercise every day)
- **〜ましょうか** — shall we? / shall I?: てつだいましょうか (Shall I help?)
- **Negative future** — use the negative non-past (**ない** / **ません**): あした は いきません (I will not go tomorrow) → see [Present Negative - ない](./present/nai-form)
:::
